# GameClub – Система автоматизации учета сессий игрового клуба

**Игровой клуб** – это десктопное приложение на WPF для автоматизации бизнес-процессов компьютерного клуба. 
Система позволяет вести учёт посетителей, управлять рабочими местами (ПК), комплектующими, тарифами и играми, а также оформлять и завершать игровые сессии с автоматическим расчётом стоимости.

Приложение поддерживает разграничение прав доступа: администратор управляет справочниками, а сотрудник (менеджер) работает с клиентами и сессиями.

## Установка (Installation)

Для запуска проекта вам потребуется:
* **Visual Studio 2022** (с установленной нагрузкой «Разработка классических приложений .NET»).
* **Microsoft SQL Server** (Express-редакции достаточно).
* **.NET Framework 4.7.2**.

### Шаг 1. Клонирование репозитория
```bash
git clone https://github.com/Fesdogxvan/GameClubApp.git
cd GameClub
```
### Шаг 2. Развёртывание базы данных
1. Откройте **SQL Server Management Studio (SSMS)**.
2. Выполните скрипт `01_GameClub_Create.sql` (создание БД и таблиц).
3. Выполните скрипт `02_GameClub_TestData.sql` (загрузка тестовых данных).
### Шаг 3. Настройка подключения
Откройте файл `App.config` в проекте `GameClub` и убедитесь, что в строке подключения `data source` указан правильный сервер (например, `localhost\SQLEXPRESS`).
### Шаг 4. Запуск
1. Откройте решение `GameClub.sln` в Visual Studio.
2. Нажмите `F5` (или «Запустить»).

**Тестовые аккаунты для входа:**
* **Администратор:** Логин `admin` / Пароль `admin`
* **Сотрудник:** Логин `employee1` / Пароль `1234`

## Использование (Usage)

1. **Авторизация:** При запуске введите логин и пароль.
2. **Главная страница:** Отображает текущий статус всех ПК в клубе (Свободен, Занят, Обслуживание).
3. **Сессии:** Здесь происходит основная работа. Выберите клиента, свободный ПК, тариф и игру, затем нажмите «Старт». При завершении сессии система автоматически рассчитает стоимость.
4. **История:** Просмотр всех завершённых сессий с фильтрацией по клиентам, ПК и датам.
5. **Справочники (только для Admin):** Управление клиентами, тарифами, играми и комплектующими (CRUD-операции).

## Данные (Data)

Приложение использует реляционную базу данных **Microsoft SQL Server**.
Схема БД (9 таблиц) создавалась по подходу **Database First** с использованием **Entity Framework 6**.

**Основные сущности:**
* `Users` – сотрудники (Admin / Employee).
* `Customers` – клиенты клуба.
* `Workstations` – рабочие места (ПК).
* `Sessions` – игровые сессии (связывает клиента, ПК, тариф и игру).
* `Components` / `ComponentTypes` – комплектующие и их типы.
* `Tariffs` – тарифы (Стандарт, VIP, Ночной).
* `Games` – каталог игр.

*Полная схема БД и ER-диаграмма находятся в файле `GameClubModel.edmx` внутри проекта.*

## Тестирование

В проект включены 18 unit-тестов (xUnit) для проверки бизнес-логики:
* Расчёт стоимости сессий (`CostCalculator`).
* Хеширование паролей (`PasswordHasher`).
* Проверка совместимости игр и ПК (`GameCompatibilityChecker`).
* Валидация старта сессии (`SessionValidator`).

Для запуска тестов: `Тест -> Обозреватель тестов -> Запустить все`.
